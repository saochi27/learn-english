# Học tiếng Anh — IELTS

Ứng dụng web học tiếng Anh theo giáo trình 50 unit, chạy hoàn toàn trong trình duyệt.

## Dùng

Mở địa chỉ GitHub Pages của repo này. Trên điện thoại, thêm vào màn hình chính
để chạy toàn màn hình như app.

## Có gì

- **Bài học** — từ vựng (từ · phiên âm IPA · nghĩa · âm thanh), mẫu câu, ngữ pháp
- **Bài tập** — chấm tự động, chỉ đáp án đúng, tự ghi lỗi
- **Mẫu câu** — phát tự động để đọc theo, chỉnh số lần lặp và giây chờ
- **Truyện / Hội thoại** — đọc từng câu, 3 chế độ hiển thị, tô từ theo cấp độ
- **Đề thi** — 50 đề, bấm giờ, chấm điểm, có bài mẫu Writing/Speaking
- **Ôn tập** — lặp ngắt quãng 1·3·7·16·35·90 ngày, 3 loại thẻ mỗi từ
- **Sổ lỗi** — gom nhóm lỗi hay mắc để biết cần học lại gì

## Lưu ý

- Tiến độ lưu trong trình duyệt của **từng thiết bị**, không đồng bộ giữa các máy.
  Xoá dữ liệu trình duyệt là mất tiến độ.
- Chấm phát âm bằng Praat chỉ có ở bản chạy trên máy tính (cần Python).
- Hoạt động offline sau lần mở đầu tiên.
